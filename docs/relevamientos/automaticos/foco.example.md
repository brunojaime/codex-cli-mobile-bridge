# Foco del proyecto

Priorizar los permisos de usuarios y el flujo de aprobación.

Identificar quién puede crear, revisar, aprobar y corregir cada operación; detectar pasos confusos, excepciones y validaciones faltantes. Proponer mejoras y próximos pasos concretos.

Mantener el relevamiento general de los demás temas del proyecto. No asumir que las propuestas ya están aprobadas.

Este foco es un ejemplo para copiar a `foco.md` del proyecto elegido. No está aplicado a ningún proyecto. Se propone que el foco guardado siga vigente hasta editarlo o borrarlo.
