# Prompt breve para iniciar en otro Codex

Trabajá en el proyecto `codex-cli-mobile-bridge`. Leé `AGENTS.md` y el documento completo `docs/relevamientos/CODEX_BRIDGE_RELEVAMIENTOS.md` e implementá el flujo allí solicitado. Empezá inspeccionando el Bridge DEV y sus integraciones reales; reutilizá lo existente, registrá los criterios de aceptación antes de editar código, implementá por etapas, ejecutá pruebas y documentá evidencia, operación y bloqueos. Conservá todo el alcance del documento, protegé secretos y grabaciones y no modifiques repositorios de clientes. Antes de concluir que un repositorio GitHub no existe por un 404, verificá mediante herramientas autenticadas del host, como `gh repo view OWNER/REPO` o `git ls-remote`. Dejá los resultados y la documentación dentro del workspace, con enlaces accesibles desde el chat.

Si esta sesión está en otra computadora, adjuntá también `CODEX_BRIDGE_RELEVAMIENTOS.md`; la ruta anterior corresponde al checkout donde se preparó este pedido.
